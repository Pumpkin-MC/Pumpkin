PumpkinPie

A bleeding-edge personal fork of Pumpkin, a Minecraft server written in Rust.

What this is

PumpkinPie tracks master on the upstream Pumpkin-MC/Pumpkin repository and layers in vanilla-parity fixes and features ahead of when they land upstream. It stays merged forward against upstream regularly rather than drifting into a permanent divergence.
